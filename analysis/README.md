# Intermediate artifacts

The single submitted prediction table is [predictions.csv](../predictions.csv). See [METHODOLOGY.md](METHODOLOGY.md) for the complete report.

| Artifact | Purpose |
| --- | --- |
| `input_manifest.json` | Frozen input hashes, allowed sets, game-file provenance and software versions |
| `cards.jsonl.gz` | Normalized supplied card text; excludes commercial/popularity metadata |
| `historical_all.csv`, `summary_*.json` | Reconstructed GIH and other diagnostics, sample sizes, population and archetype summaries |
| `unmatched_historical.csv` | Outcome rows not assigned invented text when supplied extracts lack a match |
| `validation_all.csv.gz`, `validation_metrics.csv` | All set-held-out learned-model predictions and errors |
| `model_predictions.csv` | Full historical-data machine outputs for the target cards |
| `calibration_cards.jsonl`, `expert_calibration_grades.json` | Frozen historical human-grading inputs |
| `expert_validation*.csv`, `expert_calibration_models.json` | Initial grade calibration and comparisons |
| `refined_calibration_*.csv`, `refined_calibration_models.json` | Nonlinear/impact calibration comparisons, out-of-fold predictions and fitted coefficients |
| `target_expert.tsv`, `target_cards.txt` | Individual assessment and supplied rules text for every target card |
| `archetype_*.csv` | Color-pair feature construction, held-out forecasting checks and conservative target context |
| `mechanic_census.csv` | Pattern-derived role/enabler census; broad candidates, not a promise that every match fills that role |
| `land_name_simulation.csv`, `federation_simulation.csv`, `station_simulation.csv`, `dilemma_consistency.csv` | Controlled mechanic-consistency and sensitivity exercises |
| `validation_without_OM1.csv.gz`, `model_predictions_without_OM1.csv`, `om1_ablation_metrics.csv` | Check whether historical Pick Two examples help ordinary Premier Draft prediction |
| `final_settings.json`, `prediction_components.csv` | Exact final blend, target-only judgment adjustments and decomposition |
| `prediction_summary.json`, `verification.json` | Scope, output statistics/hash and independent data-integrity checks |

Large redundant working files (uncompressed normalized cards, separate copies of each historical/validation table and per-card color tables) are regenerated by the scripts and are not separate prediction deliverables. The `cards.jsonl.gz` archive can also be decompressed to `cards.jsonl` for inspection without rerunning extraction.

Full validation-row archives are compressed for reliable publication. Training regenerates the ordinary CSV working files; decompressing the archives also recovers them byte for byte.
